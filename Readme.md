Welcome to my Decode Labs Internship Portfolio. It is a 4 weeks program where I aim to learn the basics of Data Analysis and create real word projects from start to finish.

The basic structure of the Internship is as follows:

1. Week 1 - This covers data cleaning and preparation for analysis, using Excel.

2. Week 2 - This week handles Exploratory Data Analysis on the data cleaned in Week 1. Using Excel, the task is to Analyze a dataset to understand patterns, trends, and distributions.
The task for the week aims to teach key skills: Data analysis, descriptive statistics and analytical thinking

3. Week 3 - This week covers SQL. The goal of the week is to use SQL queries to extract insights from a dataset.
The task for the week aims to teach key skills: SQL fundamentals, querying data, filtering and grouping
